# StudyFlow

StudyFlow is a study planning app designed to help students stay consistent with their study schedules.

## Features

- Create study sessions
- Plan daily timetable
- Study session timer
- Learning reflection after each session
- Progress tracking
- Responsive design
- Health check page

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Getting Started

```bash
npm install
npm run dev
